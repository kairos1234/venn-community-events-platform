    About this demo

    Venn is a small Community Events Platform built as a take-home exercise. Visitors browse published events and register anonymous interest, Organisers create and manage events, and Administrators review and publish them.

    Roles

    There is no sign-in. The “Continue as” menu switches the demo role, and the chosen role is sent with each request. The server enforces what each role may do, but this is for demonstration only and is not real security.

    Privacy

    Registering interest is anonymous. Only a registration ID, the event ID and a timestamp are stored: no names, emails or other personal details. All events and data shown here are fictional.
